
## Codex Prompt

请根据以下要求，重构并优化我的微信小程序前端项目，项目主题为“基于动作识别与心率血氧监测的康复训练辅助系统 Smart-B”。

### 一、目标
请将当前小程序优化为一个**界面美观、风格统一、切换自然流畅**的康复训练类产品，而不是简单的数据展示页面。

### 二、核心要求
1. 整体视觉风格采用“简洁医疗科技风”
2. 页面布局使用卡片式设计，统一圆角、阴影、留白和配色
3. 强调页面美观，突出专业感、健康感、科技感
4. 强调页面之间的切换流畅，尤其是：
   - 首页 → 训练页
   - 训练页 → 完成页
   - 我的页 → 设置页
5. 所有页面需要保证信息层级清晰，重点突出，不要堆叠杂乱信息
6. 对空状态、加载状态、异常状态进行完整设计
7. 增加适当的微交互和动效，如按钮点击反馈、数据更新动效、进度变化动效

### 三、页面结构要求

#### 1. 首页
包含以下模块：
- 顶部欢迎区（昵称、日期、训练状态）
- 今日训练计划卡（计划名称、完成次数、剩余次数、进度条、开始训练按钮）
- 设备状态卡（连接状态、同步时间）
- 健康监测卡（心率、血氧、状态标签）
- 快捷入口区（训练记录、训练计划、健康数据、设置）

要求：
- 首页突出“今日训练任务”
- 开始训练按钮明显
- 卡片排版舒适，层级明确

#### 2. 训练页
包含以下模块：
- 当前训练状态栏（计划名称、动作名称、设备状态）
- 核心进度区（目标次数、已完成、剩余、进度条）
- 动作识别反馈区（当前识别动作、置信度、提示语）
- 生理监测区（心率、血氧、安全状态）
- 控制按钮区（开始、暂停、继续、结束）

要求：
- 这是核心页面，需要重点优化视觉与交互
- 动作次数更新要有动态反馈
- 训练过程中的异常提醒要明显但不突兀

#### 3. 训练完成页
包含以下模块：
- 完成提示
- 本次训练总结（时长、完成动作数、完成率、平均心率、最低血氧）
- 建议区
- 操作按钮（查看详情、返回首页）

要求：
- 页面要有成就感和鼓励感
- 视觉风格与前面页面统一

#### 4. 历史数据页
包含以下模块：
- 今日总结卡
- 近 7 天趋势区
- 动作统计区
- 历史记录列表

要求：
- 页面更偏“分析”和“总结”
- 要比当前简单罗列数据更有层次感

#### 5. 我的页
包含以下模块：
- 用户信息卡（头像、昵称、训练目标、连续训练天数）
- 功能入口列表（我的计划、训练记录、健康档案、设备管理、功能建议、关于项目）
- 页脚说明

#### 6. 设置页
包含以下模块：
- 基础信息（头像、昵称、手机号、年龄、性别、身高、体重、BMI）
- 康复信息（康复部位、训练目标、当前阶段、医嘱说明、禁忌动作）
- 预警参数（心率上限、血氧下限、异常提醒开关）
- 保存按钮

### 四、设计规范要求
1. 使用统一配色方案：
   - 主色为蓝色
   - 正常状态为绿色
   - 提醒状态为橙色
   - 异常状态为红色
2. 所有页面统一采用圆角卡片设计
3. 统一按钮样式、标题样式、文字层级、图标风格
4. 优化页面留白和模块间距，提升整体美观度
5. 保证手机端显示效果自然舒适

### 五、交互要求
1. 页面切换自然流畅，不要生硬
2. 底部 tab 切换有高亮状态
3. 训练页数据更新要有反馈动画
4. 加入空状态、加载状态、异常状态组件
5. 结束训练时增加确认弹窗
6. 数据保存成功时增加 toast 提示

### 六、工程要求
2. 尽量拆分公共组件，提高复用性
3. 代码结构清晰，命名规范
4. 样式统一抽离，避免重复写死

### 七、输出要求
请按以下顺序输出：
1. 页面重构方案说明
3. 公共组件设
5. 全局样式建议
6. 可选的动效与交互优化建议

请优先保证：
**页面美观、层次清晰、功能切换自然流畅、整体像一个完整的康复训练产品。**
